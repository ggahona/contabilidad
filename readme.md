## Características técnicas

- **Archivos HTML autocontenidos:** cada archivo incluye CSS y JS embebidos, sin dependencias externas.
- **Presentaciones:** 6 slides por punto, con navegación por teclado, índice lateral, barra de progreso y URL con hash.
- **Herramientas aplicativas:** actividades interactivas con cálculo en tiempo real, aleatorización en cada reinicio, calificación inmediata y validaciones activas.
- **Exámenes finales:** banco de 20+ reactivos conceptuales por punto, selección aleatoria de 10, calificación inmediata.
- **Diseño responsivo:** funciona en pantalla de computadora, tablet y móvil.

## Uso

1. Abre el [`index.html`](index.html) en tu navegador para ver la página principal del curso.
2. O accede directamente a la [versión publicada en GitHub Pages](https://ggahona.github.io/contabilidad/).
3. Cada punto del curso tiene:
   - Una **presentación** para revisar los conceptos.
   - Una **herramienta aplicativa** para practicar con actividades interactivas.

**Recomendación de uso:**
1. Lee primero la **presentación** del punto.
2. Abre después la **herramienta aplicativa** para reforzar con actividades interactivas.
3. Usa el botón **"Cargar caso"** para restaurar los datos originales.
4. Verifica los **dos puntos de contacto** entre el ER y el BG al terminar el Punto 5.
